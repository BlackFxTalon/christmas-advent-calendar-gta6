# Telegram-бот «12 дней до полуночи» — прототип

В папке находятся ядро диалога, webhook-адаптер и PostgreSQL-хранилище прогресса. Подключены дела №1–3; тексты совпадают с текущим сценарием в `content/cases-01-12.md`. PostgreSQL-схема совместима с Supabase; код не требует включения managed database в WebDev.

## Логика и сохраняемые данные

- `/start`, `/help`, `/today`, `/progress`;
- `/case 1`, `/case 2`, `/case 3` только при `BOT_PREVIEW_MODE=1`;
- выдача дел по датам 20, 21 и 22 декабря с настраиваемым `BOT_TIME_ZONE`;
- подсказки в три ступени через inline-кнопки или `/hint 1`;
- проверка ответов, включая разрешённые варианты; неверный ответ не блокирует следующую попытку;
- отправка карточки улики отдельным фото-сообщением;
- состояние сохраняется отдельно по Telegram `from.id` и номеру дела: начато/решено, число попыток, достигнутая ступень подсказки, времена начала и решения.

Бот не записывает имя пользователя, текст переписки или введённые ответы. Команда `/progress` показывает сводку по подключённым делам только в личном чате, чтобы не раскрывать её в группе. Хранилище работает через PostgreSQL-драйвер `pg`; Supabase подключается через серверный `DATABASE_URL`.

## Локальная проверка без секретов и базы

```bash
cd bot
pnpm install
pnpm test
```

Unit-тесты используют тестовое хранилище и mock PostgreSQL pool: они не подключаются к Supabase и не выполняют SQL-изменений. В текущей итерации соединение с внешней базой не проверялось.

## Подготовка схемы — только при отдельном подключении

Миграция `migrations/001_player_progress.sql` создаёт таблицы профилей и состояния дел. После того как владелец настроит `DATABASE_URL` как серверный secret, миграцию можно применить отдельной командой:

```bash
pnpm run migrate
```

Команда меняет схему внешней БД, поэтому здесь она **не запускалась**. Миграция использует версионирование и транзакцию; повторный запуск уже применённой версии не повторяет DDL.

## Серверные переменные

- `TELEGRAM_BOT_TOKEN` — токен от BotFather;
- `TELEGRAM_WEBHOOK_SECRET` — секрет webhook из букв, цифр, `_` и `-` (1–256 символов);
- `DATABASE_URL` — PostgreSQL URL из Supabase или другого PostgreSQL-хоста;
- `BOT_TIME_ZONE` — часовой пояс календаря, по умолчанию `Europe/Moscow`;
- `BOT_PREVIEW_MODE=1` — ручная выдача `/case N` только для закрытого теста; не включать в публичном боте.

Реальные значения нельзя помещать в репозиторий или клиентский код; образец находится в `.env.example`. Сервер с включённым хранилищем без `DATABASE_URL` не запускается.

## Текущий статус подключения

Supabase, база, Telegram webhook и размещение сервера не подключены. В WebDev-проекте `server` и `database` остаются выключенными; конфигурация не менялась. Для работы нужен хостинг webhook-сервера и безопасно заданный `DATABASE_URL`; отдельно настраиваются токен Telegram и webhook-secret. Проверка доступа/оплаты и долговременное хранение прогресса в БД реализованы как основа, но проверка платного доступа не входит в эту версию.
