# Telegram-бот «12 дней до полуночи» — первая итерация

В папке находятся тестируемое ядро диалога и HTTP-адаптер для Telegram Bot API. Подключены дела №1–3; тексты совпадают с текущим сценарием в `content/cases-01-12.md`.

## Что работает в ядре

- `/start`, `/help`, `/today`;
- `/case 1`, `/case 2`, `/case 3` только при `BOT_PREVIEW_MODE=1`;
- выдача дел по датам 20, 21 и 22 декабря с настраиваемым `BOT_TIME_ZONE`;
- подсказки в три ступени через inline-кнопки или `/hint 1`;
- проверка ответов, включая разрешённые варианты записи;
- ответ засчитывается в контексте reply на сообщение с делом; неверный ответ не блокирует следующую попытку;
- отправка карточки улики отдельным фото-сообщением.

Состояние намеренно stateless: бот понимает номер дела из сообщения, на которое отвечает игрок. Он не хранит историю, очки или факт завершения. Для платного запуска нужно отдельно добавить хранение доступа и прогресса в устойчивом хранилище.

## Проверка без Telegram-токена

```bash
cd bot
npm test
```

Тесты не делают сетевых запросов и не требуют учётной записи Telegram.

## Подключение к Telegram — не выполнено

Сервер ожидает секреты только в окружении:

- `TELEGRAM_BOT_TOKEN` — токен, который выдаёт BotFather;
- `TELEGRAM_WEBHOOK_SECRET` — случайная строка из букв, цифр, `_` и `-` (1–256 символов);
- `BOT_TIME_ZONE` — часовой пояс выдачи; по умолчанию `Europe/Moscow`;
- `BOT_PREVIEW_MODE=1` — ручная выдача `/case N` для закрытого теста; не включать в публичном боте.

Запуск `npm start` требует первые два секрета. Для настоящей доставки webhook нужен публичный HTTPS URL, настройка серверной части проекта и регистрация webhook в Telegram. В текущем WebDev-проекте `server` и `database` выключены; live webhook не зарегистрирован, никаких токенов в репозитории нет.

Карточки из `public/evidence/` бот загружает в Telegram как фото. Перед подключением live webhook нужно решить, где размещать сервис, безопасно сохранить токен и webhook secret, а для платного продукта — добавить проверку доступа и долговременное хранение прогресса.
