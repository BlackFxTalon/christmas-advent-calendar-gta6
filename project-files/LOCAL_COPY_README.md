# Локальная копия файлов проекта

В эту папку скопированы доступные вложения из истории проекта. В `LOCAL_COPY_INDEX.json` перечислены локальные пути, типы файлов, размеры и SHA-256 для проверки целостности; исходные URL и текст переписки в индекс не включены.

## Структура

- `history/advent/` — документы продукта, сценарные материалы, изображения и видеотизер.
- `history/midnight12/` — исторические снимки исходников бота, миграции, тесты и конфигурационные примеры.
- `history/archives/` — прикреплённые архивы.
- `history/attachments/` — вложения без исходного пути.
- Рабочая копия бота остаётся в `../midnight12-bot/bot/`; текущий код не перезаписывался.
- В `../midnight12-bot/bot/content/` добавлены `cases-01-03.md` и `cases-01-12.md`; PNG-карточки размещены в `../midnight12-bot/public/evidence/`, откуда их читает `server.mjs`.

Фактический `.env` и его секреты не переносились и не читались. Файл `.env.example` — только шаблон конфигурации.

## Границы переноса

Перенесены все доступные файловые вложения истории текущей задачи. Отдельный исходный код лендинга из WebDev-проекта в локальной папке не обнаружен и этим переносом не экспортировался; если он нужен локально, его следует отдельно выгрузить/клонировать из WebDev/GitHub. Копии в `history/` являются архивными материалами и не заменяют текущую рабочую версию бота.
